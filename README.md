# Milésima

Sitio de noticias de Fórmula 1 en español para México y Argentina: notas diarias, posiciones del campeonato y tiempos de cada sesión con repetición vuelta a vuelta.

- Noticias: `data/noticias.json`, actualizado a diario.
- Posiciones: Jolpica F1 API.
- En vivo y repetición: OpenF1 (servicio no oficial).
- Fotos y logos: Wikimedia Commons, con autor y licencia en cada pieza.

Milésima es un medio independiente, sin relación con Formula 1, la FIA ni los equipos.
